# Personal Portfolio — MVP

A responsive dark minimalist portfolio built with plain HTML, CSS, and JavaScript.

## Before publishing

Search and replace these placeholders in `index.html`:

- `Your Name` / `YN` — your name and initials
- `YOUR_EMAIL@example.com` — your email address
- `YOUR_GITHUB` — your GitHub username
- `YOUR_LINKEDIN` — your LinkedIn profile slug

You can also edit the About, project, and interests copy to match your experience. Keep project descriptions accurate; label unfinished work as in progress.

## Preview locally

Open `index.html` in a browser. For a local development server, use VS Code's Live Server extension or run:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Publish with GitHub Pages

1. Create a new public repository named `YOUR_GITHUB_USERNAME.github.io` (replace with your GitHub username).
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then save.
6. Wait a few minutes and visit `https://YOUR_GITHUB_USERNAME.github.io`.

If you already have a personal-site repository, upload these files to its root and configure Pages to deploy from `main` / root.
